# 💖 HeartQuest

An interactive, charming HTML5 Canvas mini-game designed for Valentine's & Propose Day. Players catch falling hearts with a basket to fill up the **Love Meter**, unlocking a surprise interactive proposal card complete with a playful runaway "No" button and celebratory confetti effects!

---

## ✨ Features

- 🎮 **Dynamic Canvas Gameplay**: Smooth HTML5 Canvas game loop featuring falling hearts, particle effect animations, and continuous score tracking.
- 💖 **Love Meter Progress Bar**: Interactive UI element that dynamically fills up as you catch hearts.
- 🏃‍♂️ **Playful Runaway "No" Button**: The "No" button dynamically teleports away when hovered or touched, ensuring a lighthearted guaranteed "YES!".
- 🎉 **Celebration & Particle Effects**: Particle explosion and custom visual fireworks celebrate when "YES!" is clicked.
- 📱 **Mobile & Desktop Responsive**: Supports mouse movements and touch gestures, with dynamic canvas recalculations on screen resize or device orientation changes.
- 🎨 **Modern Aesthetic Design**: Built with Google Fonts (*Great Vibes* & *Poppins*), soft pink/red gradients, and sleek modern CSS overlays.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic layout & HTML5 `<canvas>` rendering element.
- **CSS3**: Flexible viewport-fit layouts, glassmorphism overlays, custom animations, and responsive media queries.
- **JavaScript (ES6+)**: Custom Canvas 2D engine, collision detection, physics particle effects, and touch/mouse input handlers.

## 🚀 Quick Start / Local Setup

No external dependencies, Node.js packages, or build tools required! Simply run directly in any browser:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VarunJoshi591/HeartQuest.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd HeartQuest
   ```

3. **Open `index.html` in your web browser:**
   - Double click `index.html` or open it using any modern web browser (Chrome, Firefox, Edge, Safari).
   - Alternatively, serve via VS Code Live Server or python standard HTTP server:
     ```bash
     python -m http.server 8000
     ```

## 🎮 How to Play

1. Click **"Start Game"** to begin.
2. Move your mouse or drag on touchscreens to slide the basket left and right.
3. Catch falling hearts to build up your **Love Meter**.
4. Reach the target score to reveal the **Special Proposal**!
5. Try clicking "No" (if you can!) or click **"YES!"** to trigger the celebration!
